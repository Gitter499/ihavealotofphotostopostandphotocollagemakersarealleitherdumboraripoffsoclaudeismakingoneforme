# Where photogram stands against the collage apps

Compared against the big ones — PicCollage, PhotoGrid, InCollage, Canva's collage
tool, MOLDIV, Adobe Express — using their store listings and 2026 roundups.
Everything here runs on your device. No account, no watermark, no paid tier, no
ads, no server. That column doesn't exist for the others.

| Feature | Them | photogram |
| --- | --- | --- |
| Grid layout templates | thousands, mostly filler | 31 curated classics + an automatic BSP composer that generates a fresh layout for any 1–8 photos, aspect-aware |
| Auto arrangement | pick a template yourself | chronological grouping with time-gap cuts, hero solos, orientation balance, colour harmony |
| Freeform / scrapbook | drag things anywhere | polaroid-toss templates with paper mats, tilt, corner rounding |
| Smart crop | some face detection | saliency focal point per photo (center-surround contrast, on-device); every crop slides toward the subject |
| Best-shot selection | rare | sharpness/exposure/contrast scoring steers the best photo into the biggest slot |
| Duplicate handling | none | perceptual-hash burst detection; only the best of a burst gets prominence, remix can split twins apart |
| Filters | hundreds, mostly noise | 12 looks + adaptive Auto with a strength dial, live preview bubbles, colour-matrix engine (works in Safari), Off guard |
| Text / captions | fonts, stickers, doodles | per-slide captions, display type over an auto scrim, top/bottom, baked into exports |
| Backgrounds | patterns, papers | near-black, off-white, or sampled from your photos |
| Borders & spacing | yes | gutter, stroke borders with colour, corner radius, per-photo tilt |
| Aspect presets | many | 4:5, 1:1, 9:16, plus any custom W:H |
| Multi-slide carousels | single collages | the whole product: up to 20 slides; merged slides compose as one wide canvas cut at marked lines, so the carousel swipes as one strip |
| Resize a photo in place | pinch, fiddly | tap → slider; the layout reflows around it, crop guard intact |
| Rotate / flip | buried in submenus | tap → rotate 90° / mirror; the focal point rides along and layouts reflow |
| Staging area | none | the playground shelf — park photos while you experiment |
| Shuffle | random | Remix: colour runs, light arcs, mosaics, hero anchors, twins apart, chance — never the same lens twice |
| Export | often watermarked/paywalled | numbered JPEGs or PNGs in a zip — Post (1440), HD (2160) or Print (3240) wide, quality 0.95 |
| Mobile | native apps | installable PWA (offline after first visit) + Capacitor projects for real iOS/Android builds |
| Video collages | yes | no — photogram is for photo carousels |
| AI background removal / generative expand | cloud-served | no — nothing leaves the device, by design |
| Stickers | 5,000+ | no — captions and layouts carry the design |

The last three rows are deliberate. Everything that would need a server, a
model download, or an asset store is out; everything algorithmic that can run
in a worker on your own photos is in.
